# 부하 테스트 이후 인프라 개선 과제 및 리뷰 질문

> 원본: Notion "인프라 개선 내용" (Infra > 작업목록). 작성: 인프라·배포 설계 담당, 2026-02-25 (최종 발표 직후).

## 부하 테스트에서 드러난 문제
- ArgoCD에서 신버전 문제 발생 시 구버전으로 롤백되지 않음
- 부하 발생 시 서비스가 버티지 못함
- Redis 커넥션 풀 부족
- DB 커넥션 풀 부족

## 도입(검토)하지 못한 항목
- 서비스별 Argo Rollout 트래픽 가중치 및 자동 롤백 정책
- DB 과부하/장애 시 데이터 복구·정합성 관리 방안
- USE Method / RED Method 기반 모니터링 체계
- 메트릭별 임계값의 근거 정리
- Grafana Alerting → Discord Webhook 발송 조건 정리
- Kafka Consumer Lag 기반 확장 정책
